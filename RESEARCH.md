# Ballot Marking Rule Change Gate

Stage 1: stale or incomplete ballot-help instructions can misstate marking, correction, assistance, or return actions. Validators compare a proposed help revision with one official instruction vector. Actors: election authority, publisher, observer, validator, publication workflow. Consequence: `PUBLISH_CURRENT`, `HOLD_STALE_RULE`, `MANUAL_AUTHORITY_CHECK`. Unlike generic public-notice revision projects, it gates only explicit voter-action fields. Stage 2: official version sealed, help submitted, assessed/superseded; register/seal/submit/assess and action-vector views. Bind jurisdiction/election/version, marking, overvote/correction, assistance, return role, masks and result. Authority sealing, publisher submission, source allowlist, no eligibility or winner claims; ambiguity, injection, disagreement and replay fail closed. Tests cover equivalent wording, stale rule, omission, wrong election, disagreement and supersession. Static official PDFs make one-call Studionet deployment feasible; high civic-risk requires conservative wording.
